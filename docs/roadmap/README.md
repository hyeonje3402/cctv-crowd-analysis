# 결과 해석과 개선 로드맵

[메인 README](../../README.md)

## 현재 범위

저장소에는 CSRNet 기반 밀도 추정, YOLOv8 기반 사람 탐지, JSON 출력, 시각화 스크립트가 있습니다. 결과는 영상 해상도, 촬영 각도, 가림, 영상 길이, 장면별 인구 밀도에 따라 달라집니다.

CSRNet과 YOLO 경로는 서로 다른 임계값을 사용하므로 혼잡도 표기는 각 알고리즘 안에서 해석해야 합니다. 현재 정답 라벨 기반 오차 통계나 운영 서비스 모니터링은 포함되어 있지 않습니다.

## 다음 마일스톤 제안 — v0.2.0

이 버전은 제안 단계입니다.

- 입력·출력 디렉터리와 모델 경로를 CLI 옵션 또는 설정 파일로 통일
- 두 분석 결과의 공통 JSON 스키마와 임계값 설정 형식 정의
- 구역별 면적을 반영한 밀도(명/㎡) 지표와 단계 기준 분리
- 정답 인원 수가 표시된 검증 데이터셋으로 MAE/RMSE 및 혼잡 단계 정확도 측정
- 프레임 처리 실패, 잘못된 영상, 빈 영상에 대한 오류·로그 처리 보강
- 작은 샘플 영상으로 실행 회귀 검증 자동화

## 배포 계획

현재 저장소에는 API 서버, DB, 컨테이너, CI/CD 또는 호스팅 설정이 없습니다. 이를 웹 서비스로 발전시키려면 업로드·작업 큐·저장 공간·접근 권한·영상 보관 정책을 먼저 설계해야 합니다.
