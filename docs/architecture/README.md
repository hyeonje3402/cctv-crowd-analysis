# 분석 아키텍처와 알고리즘

[메인 README](../../README.md)

## 두 분석 파이프라인

### CSRNet 밀도 추정 — analyze_crowd.py

- VGG 스타일 프런트엔드와 dilated convolution 백엔드로 구성된 CSRNet을 사용합니다.
- 영상 프레임을 896×384 크기로 조정한 뒤 밀도 맵을 계산하고 인원 수를 추정합니다.
- 코드에 설정된 기본 구간은 150명부터 주의(CAUTION), 300명부터 혼잡(CONGESTED)입니다.
- 가중치 파일이 없으면 설정된 Hugging Face URL에서 CSRNet 가중치를 내려받도록 되어 있습니다.

### YOLOv8 객체 검출 — batch_crowd_analysis.py

- Ultralytics YOLO 모델로 사람 클래스(class 0)만 검출합니다.
- 영상 FPS를 이용해 약 1초마다 프레임을 분석합니다.
- 코드에 설정된 기본 구간은 25명부터 주의, 50명부터 혼잡입니다.
- 영상별 구역 ID는 ZONE_MAP에 지정하거나 자동 번호를 사용할 수 있습니다.

두 파이프라인의 임계값은 서로 다릅니다. 인원 수를 혼잡도 기준으로 해석하려면 영상 공간의 면적과 안전 기준에 맞춘 별도 보정이 필요합니다.

## 데이터 흐름

1. 스크립트가 프로젝트 루트의 videos/에서 영상 파일을 찾습니다.
2. 선택된 모델로 프레임을 분석합니다.
3. 시각화 가능한 프레임별·구역별 결과를 JSON 파일로 기록합니다.
4. visualize_crowd.py가 분석 결과를 읽어 결과를 시각화합니다.

현재 저장소 구성은 로컬 파일 기반 분석 도구입니다. API 서버, 데이터베이스, 인증, 클라우드 스토리지는 확인되지 않습니다.
